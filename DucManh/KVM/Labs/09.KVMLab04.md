# Tạo máy ảo và mạng sử dụng XML
## Tạo mạng sử dụng XML
Tạo file định nghĩa mạng
```
cat <<EOF > lab-network.xml
<network>
  <name>lab-net</name>
  <forward mode='nat'/>
  <bridge name='virbr10' stp='on' delay='0'/>
  <ip address='192.168.100.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.100.10' end='192.168.100.100'/>
    </dhcp>
  </ip>
</network>
EOF
```
Kiểm tra
```
# Nạp cấu hình XML vào KVM
root@MANHLAB1:~# virsh net-define lab-network.xml
Network lab-net defined from lab-network.xml

# Bật mạng
root@MANHLAB1:~# virsh net-start lab-net
Network lab-net started

# Cho phép mạng tự khởi động vào OS
root@MANHLAB1:~# virsh net-autostart lab-net
Network lab-net marked as autostarted

# Kiểm tra trạng thái và giao diện Bridge vừa tạo
root@MANHLAB1:~# virsh net-list --all
 Name      State    Autostart   Persistent
--------------------------------------------
 default   active   yes         yes
 lab-net   active   yes         yes

root@MANHLAB1:~# ip a show virbr10
11: virbr10: <NO-CARRIER,BROADCAST,MULTICAST,UP> mtu 1500 qdisc noqueue state DOWN group default qlen 1000
    link/ether 52:54:00:81:13:43 brd ff:ff:ff:ff:ff:ff
    inet 192.168.100.1/24 brd 192.168.100.255 scope global virbr10
       valid_lft forever preferred_lft forever
```
## Tạo đĩa đệm cho máy ảo
Tạo đĩa đệm định dạng qcow2 dung lượng 5GB đặt tại thư mục mặc định của KVM:
```
root@MANHLAB1:~# qemu-img create -f qcow2 /var/lib/libvirt/images/demo-vm.qcow2 5G
Formatting '/var/lib/libvirt/images/demo-vm.qcow2', fmt=qcow2 cluster_size=65536 extended_l2=off compression_type=zlib size=5368709120 lazy_refcounts=off refcount_bits=16
```
## Tạo và định nghĩa Máy ảo (demo-vm) bằng XML
Tạo file cấu hình máy ảo demo-vm.xml:

```Bash
cat <<EOF > demo-vm.xml
<domain type='kvm'>
  <name>demo-vm</name>
  <memory unit='KiB'>1048576</memory>
  <currentMemory unit='KiB'>1048576</currentMemory>
  <vcpu placement='static'>1</vcpu>

  <os>
    <type arch='x86_64' machine='pc-q35-8.1'>hvm</type>
    <boot dev='hd'/>
  </os>

  <features>
    <acpi/>
    <apic/>
  </features>

  <clock offset='utc'/>
  <on_poweroff>destroy</on_poweroff>
  <on_reboot>restart</on_reboot>
  <on_crash>destroy</on_crash>

  <devices>
    <emulator>/usr/bin/qemu-system-x86_64</emulator>

    <!-- Khai báo Đĩa đệm -->
    <disk type='file' device='disk'>
      <driver name='qemu' type='qcow2'/>
      <source file='/var/lib/libvirt/images/demo-vm.qcow2'/>
      <target dev='vda' bus='virtio'/>
    </disk>

    <!-- Khai báo Card mạng cắm vào lab-net vừa tạo -->
    <interface type='network'>
      <source network='lab-net'/>
      <model type='virtio'/>
    </interface>

    <!-- Khai báo Console hỗ trợ thao tác CLI -->
    <console type='pty'>
      <target type='serial' port='0'/>
    </console>

    <graphics type='vnc' port='-1' autoport='yes' listen='127.0.0.1'/>
  </devices>
</domain>
EOF
```
Khai báo và khởi động máy ảo
```
root@MANHLAB1:~# virsh define demo-vm.xml
Domain 'demo-vm' defined from demo-vm.xml

root@MANHLAB1:~# virsh start demo-vm
Domain 'demo-vm' started
```
Kiểm tra danh sách máy ảo
```
root@MANHLAB1:~# virsh list --all
 Id   Name      State
-------------------------
 6    vm2       running
 7    vm1       running
 8    demo-vm   running
```
# Chỉnh sửa VM với XML
Mọi thao tác chỉnh sửa phần cứng máy ảo thông qua XML đều được thực hiện an toàn nhất bằng lệnh:
```Bash
virsh edit <tên_vm>
```
### Thêm một Đĩa cứng phụ (Add New Data Disk)
Bước 1: Tạo file đĩa đệm mới trên HostTạo thêm file đĩa đệm demo-vm-data.qcow2 dung lượng 10GB và gán quyền cho KVM:
```Bash
qemu-img create -f qcow2 /var/lib/libvirt/images/demo-vm-data.qcow2 10G
chown libvirt-qemu:kvm /var/lib/libvirt/images/demo-vm-data.qcow2
chmod 660 /var/lib/libvirt/images/demo-vm-data.qcow2
```
Bước 2: Thêm thẻ `<disk>` vào XML. Mở cấu hình máy ảo:
```Bash
virsh edit demo-vm
```
Tìm đến thẻ `<devices>` và chèn thêm khối XML sau vào dưới đĩa vda hiện có:
```XML    <!-- Đĩa cứng phụ (Data Disk) -->
    <disk type='file' device='disk'>
      <driver name='qemu' type='qcow2' cache='none' io='native'/>
      <source file='/var/lib/libvirt/images/demo-vm-data.qcow2'/>
      <target dev='vdb' bus='virtio'/>
    </disk>
```
Lưu ý: Thẻ `dev='vdb'` phải khác với đĩa chính vda. Bạn không cần khai báo thẻ `<address type='pci'.../>`, Libvirt sẽ tự động gán slot PCI hợp lệ khi lưu.
## Chỉnh sửa Card mạng (Modify Network Interface)
Để thay đổi Virtual Network kết nối, địa chỉ MAC, hoặc loại card mạng:

Bước 1: Mở XML 
```Bash
virsh edit demo-vm
```
Bước 2: Tìm khối <interface> và điều chỉnh. Tìm đến thẻ <interface> trong <devices>:
```XML    
<!-- CẤU HÌNH CŨ: Đang nối vào lab-net -->
    <interface type='network'>
      <mac address='52:54:00:ab:cd:ef'/>
      <source network='lab-net'/>
      <model type='virtio'/>
    </interface>
```
Sửa lại thuộc tính network='default' (hoặc chuyển sang Bridge type='bridge'):
```XML    <!-- CẤU HÌNH MỚI: Chuyển sang mạng 'default' (NAT 192.168.122.x) -->
    <interface type='network'>
      <mac address='52:54:00:ab:cd:ef'/>
      <source network='default'/>
      <model type='virtio'/>
    </interface>
```
## Xóa Card mạng (Delete Network Interface)
Bước 1: Mở XMLBashvirsh edit demo-vm

Bước 2: Xóa khối thẻ. Xóa hoàn toàn toàn bộ đoạn thẻ từ <interface> đến </interface> tương ứng với card mạng muốn loại bỏ:
```XML    
<!-- XÓA BỎ HOÀN TOÀN KHỐI NÀY NẾU MUỐN THÁO CARD MẠNG -->
    <interface type='network'>
      <mac address='52:54:00:ab:cd:ef'/>
      <source network='default'/>
      <model type='virtio'/>
    </interface>
```
Lưu và thoát trình biên soạn (:wq trong Vi/Vim hoặc Ctrl+O $\rightarrow$ Enter $\rightarrow$ Ctrl+X trong Nano).
# Một số lưu ý
Không sửa trực tiếp file trong /etc/libvirt/qemu/*.xml bằng vim/nano thông thường:

Luôn dùng bộ lệnh virsh edit:Máy ảo: virsh edit <máy_ảo>Mạng ảo: virsh net-edit <mạng_ảo>

Sửa file XML độc lập (Offline File):

Khi copy file XML từ một máy ảo mẫu để tạo máy ảo mới, bạn bắt buộc phải xử lý các trường sau để tránh xung đột:
- Thẻ `<name>`: Phải đặt tên duy nhất, không trùng với các VM khác trong hệ thống.
- Thẻ `<uuid>`: Xóa bỏ hoàn toàn dòng này. Libvirt sẽ tự động tạo một mã UUID mới chuẩn 128-bit khi bạn chạy virsh define.
- Thẻ `<mac address='...'/>`: Xóa bỏ thẻ này (hoặc đổi thành địa chỉ MAC khác). Nếu để trùng MAC, 2 máy ảo chạy cùng lúc sẽ gây hiện tượng đụng độ ARP/MAC trên Switch ảo.
- Thẻ `<source file='...'/>`: Đảm bảo trỏ đúng đến file đĩa `.qcow2/.raw mới`. 
- Đồng bộ Chuẩn Phần cứng & Bus Thiết bị (Hardware & Bus Matching)
