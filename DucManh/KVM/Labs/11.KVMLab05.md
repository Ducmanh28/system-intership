## Lab Block Migration
Trước khi chạy, hãy đảm bảo 2 điều sau được thực hiện:
- Ở host Destination phải có sẵn ổ chứa OS giống Host Source
- Chỉnh sửa file etc/hosts đảm bảo khai báo đầy đủ thông tin của host 1 và host 2

Nếu không, có thể sẽ gặp phải 1 số lỗi như sau:
```bash
error: Cannot access storage file '/var/lib/libvirt/boot-iso/alpine-virt-3.20.3-x86_64.iso': No such file or directory

error: internal error: unable to execute QEMU command 'blockdev-add': address resolution failed for manh-lab-02.addc.local:49153: Name or service not known
```
Sau khi hoàn tất, chạy lệnh sau:
```
virsh migrate --live --copy-storage-all --persistent --undefinesource vm1 qemu+ssh://root@172.16.66.59/system
```
- `virsh migrate`: Lệnh chính của công cụ Libvirt dùng để di chuyển một máy ảo (Domain) từ KVM Host này sang KVM Host khác.

- `--live` (Di trú sống): Giữ máy ảo tiếp tục hoạt động liên tục trong suốt quá trình truyền dữ liệu bộ nhớ RAM và trạng thái CPU sang Host đích.

- `--copy-storage-all` (Block Migration): Chỉ thị cho QEMU/Libvirt copy toàn bộ dữ liệu ổ đĩa cục bộ (file .qcow2) từ Host nguồn sang Host đích thông qua đường truyền mạng.

- `--persistent`: Tự động đăng ký và ghi file cấu hình XML của vm1 vào thư mục /etc/libvirt/qemu/ trên Host 2

- `--undefinesource`: Tự động xóa file cấu hình XML của vm1 trên Host 1 sau khi di trú thành công.

- `vm1`: Tên máy ảo mục tiêu đang chạy trên Host 1 cần di trú.

- `qemu+ssh://root@172.16.66.59/system` (Destination URI):

  - `qemu`: Quản lý tiến trình giả lập KVM/QEMU.

  - `+ssh`: Mở kênh kết nối an toàn qua giao thức SSH đến Host đích.

  - `root@172.16.66.59`: Tài khoản root và IP của Host 2 (máy nhận VM).

- `/system`: Kết nối vào socket quản lý cấp hệ thống (libvirtd.sock) của KVM.

## Lab Shared Storages Migration
Trước tiên, chúng ta cần xóa ổ đĩa ảo cũ của vm1 ở host 1
```
rm -f /var/lib/libvirt/images/vm1.qcow2
```
Tải và cài đặt NFS Server trên Host 3
```
apt update && apt install -y nfs-kernel-server
```
Tạo thư mục chia sẻ và cấp quyền
```
mkdir -p /nfs/kvm-storage
chown -R nobody:nogroup /nfs/kvm-storage
chmod 777 /nfs/kvm-storage
```
Khai báo cấu hình Export NFS:
```
#Thêm dòng cấu hình cấp quyền cho dải mạng 172.16.66.0/24:
/nfs/kvm-storage 172.16.66.0/24(rw,sync,no_subtree_check,no_root_squash)
```
Kích hoạt và kiểm tra lại
```
root@manh-lab-03:~# exportfs -arv
exporting 172.16.66.0/24:/nfs/kvm-storage
root@manh-lab-03:~# systemctl restart nfs-kernel-server
root@manh-lab-03:~# systemctl enable nfs-kernel-server
Synchronizing state of nfs-kernel-server.service with SysV service script with /usr/lib/systemd/systemd-sysv-install.
Executing: /usr/lib/systemd/systemd-sysv-install enable nfs-kernel-server
```
### Đưa đĩa đệm của vm1 lên NFS & Mount NFS trên Host 1 và Host 2
Tạm tắt vm1 trên Host 2 để chuyển đĩa đệm lên NFS
Thực hiện trên Host 2 (172.16.66.59):

```Bash
# Tắt máy ảo vm1
virsh shutdown vm1
```
```
# Đợi máy ảo tắt hoàn toàn (kiểm tra trạng thái shut off)
virsh list --all
```
Mount tạm thời NFS vào Host 2 để chép file đĩa
```
# Cài nfs-common nếu chưa có
apt update && apt install -y nfs-common

# Mount tạm thư mục NFS
mkdir -p /mnt/nfs
mount -t nfs 172.16.66.60:/nfs/kvm-storage /mnt/nfs

# Di chuyển file đĩa .qcow2 của vm1 vào NFS
mv /var/lib/libvirt/images/vm1.qcow2 /mnt/nfs/

# Unmount thư mục tạm
umount /mnt/nfs
```
Mount chính thức NFS đè vào thư mục Storage Pool /var/lib/libvirt/images trên CẢ HAI HOST
```
# Cài đặt nfs-common trên Host 1 (nếu chưa có)
apt install -y nfs-common

# Mount NFS vào /var/lib/libvirt/images
mount -t nfs 172.16.66.60:/nfs/kvm-storage /var/lib/libvirt/images

# Ghi vào /etc/fstab để tự động mount khi reboot host
echo "172.16.66.60:/nfs/kvm-storage /var/lib/libvirt/images nfs defaults 0 0" >> /etc/fstab
```
Phân quyền và bật lại vm1 trên Host 2
```Bash
# Cấp quyền cho KVM đọc ghi file trên NFS
chown libvirt-qemu:kvm /var/lib/libvirt/images/vm1.qcow2

# Kiểm tra file vm1.qcow2 đã xuất hiện trên NFS chưa
ls -lh /var/lib/libvirt/images/vm1.qcow2

# Bật lại máy ảo vm1
virsh start vm1
```
