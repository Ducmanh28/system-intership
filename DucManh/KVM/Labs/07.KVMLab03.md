# Lab Storage KVM
## Mục tiêu
Tạo 2 đĩa ảo đại diện cho Thin và Thick.

Kiểm chứng sự khác biệt về cấu trúc và dung lượng thực tế giữa `ls`, `du`, và `qemu-img info`.

Đo đạc và so sánh hiệu năng I/O Write thực tế bằng công cụ `dd`.

## Khởi tạo 2 ổ đĩa ảo
Sử dụng `qemu-img` để khởi tạo 2 ổ đĩa ảo
```
# Khởi tạo đĩa Thin Provisioning
root@MANHLAB1:~# qemu-img create -f qcow2 /var/lib/libvirt/images/lab_thin.qcow2 10G
Formatting '/var/lib/libvirt/images/lab_thin.qcow2', fmt=qcow2 cluster_size=65536 extended_l2=off compression_type=zlib size=10737418240 lazy_refcounts=off refcount_bits=16
# Tạo đĩa Thick Provisioning
root@MANHLAB1:~# qemu-img create -f qcow2 -o preallocation=full /var/lib/libvirt/images/lab_thick.qcow2 10G
Formatting '/var/lib/libvirt/images/lab_thick.qcow2', fmt=qcow2 cluster_size=65536 extended_l2=off preallocation=full compression_type=zlib size=10737418240 lazy_refcounts=off refcount_bits=16
```
## Kiểm chứng dung lượng và cấu trúc Metadata
So sánh thông số hiển thị giữa dung lượng khai báo (Virtual Size) và dung lượng thực tế chiếm dụng trên đĩa vật lý (Physical Used Size):

-rw-r--r-- 1 root root 193K Oct 29 14:06 /var/lib/libvirt/images/lab_thin.qcow2

## Đo đạc và so sánh hiệu năng I/O
Sử dụng `dd` để so sánh
```
# Đo với Thin Provisoning
root@MANHLAB1:~# dd if=/dev/zero of=/var/lib/libvirt/images/lab_thin.qcow2 bs=1M count=2048 conv=notrunc oflag=direct
2048+0 records in
2048+0 records out
2147483648 bytes (2.1 GB, 2.0 GiB) copied, 12.4332 s, 173 MB/s
```
```
# Đo với Thick Provisioning
root@MANHLAB1:~# dd if=/dev/zero of=/var/lib/libvirt/images/lab_thick.qcow2 bs=1M count=2048 conv=notrunc oflag=direct
2048+0 records in
2048+0 records out
2147483648 bytes (2.1 GB, 2.0 GiB) copied, 6.55339 s, 328 MB/s
```
Đánh giá kết quả thu được:
- Đĩa Thick: Tốc độ MB/s sẽ cao hơn đáng kể và thời gian hoàn thành nhanh hơn do các block đĩa đã được xin sẵn từ trước, không tốn thời gian xin cấp phát cấp tốc từ Kernel.
- Đĩa Thin: Sau khi chạy lệnh dd, bạn hãy gõ lại lệnh `du -sh /var/lib/libvirt/images/lab_thin.qcow2`. Lúc này kích thước file lab_thin.qcow2 đã tự động phình to từ 200KB lên thành 2.1GB để đáp ứng đúng dữ liệu vừa được ghi vào.

```
root@MANHLAB1:~# du -sh /var/lib/libvirt/images/lab_thin.qcow2
2.1G    /var/lib/libvirt/images/lab_thin.qcow2
```

# Lab chuyển đổi giữa raw và qcow2
## Mục đích
Thực hiện chuyển đổi một file đĩa từ qcow2 $\rightarrow$ raw và ngược lại từ raw $\rightarrow$ qcow2, sau đó kiểm tra thông số file thu được bằng `qemu-img info`.

## Tạo file đĩa nguồn
Thực hiện tạo file đĩa nguồn 5gb và kiểm tra thông tin
- Tạo file đĩa nguồn 5GB
```
root@MANHLAB1:~# qemu-img create -f qcow2 /var/lib/libvirt/images/source_disk.qcow2 5G
Formatting '/var/lib/libvirt/images/source_disk.qcow2', fmt=qcow2 cluster_size=65536 extended_l2=off compression_type=zlib size=5368709120 lazy_refcounts=off refcount_bits=16
```
- Kiểm tra thông tin đĩa nguồn vừa tạo
```
root@MANHLAB1:~# qemu-img info /var/lib/libvirt/images/source_disk.qcow2
image: /var/lib/libvirt/images/source_disk.qcow2
file format: qcow2
virtual size: 5 GiB (5368709120 bytes)
disk size: 196 KiB
cluster_size: 65536
Format specific information:
    compat: 1.1
    compression type: zlib
    lazy refcounts: false
    refcount bits: 16
    corrupt: false
    extended l2: false
Child node '/file':
    filename: /var/lib/libvirt/images/source_disk.qcow2
    protocol type: file
    file length: 192 KiB (197120 bytes)
    disk size: 196 KiB
```
Ban đầu, định dạng file được tạo đang là `qcow2`
## Chuyển từ qcow2 sang raw
Thực hiện chuyển đổi
```
root@MANHLAB1:~# qemu-img convert -f qcow2 -O raw /var/lib/libvirt/images/source_disk.qcow2 /var/lib/libvirt/images/converted_disk.raw
```
Kiểm tra lại
```
root@MANHLAB1:~# qemu-img info /var/lib/libvirt/images/converted_disk.raw
image: /var/lib/libvirt/images/converted_disk.raw
file format: raw
virtual size: 5 GiB (5368709120 bytes)
disk size: 4 KiB
Child node '/file':
    filename: /var/lib/libvirt/images/converted_disk.raw
    protocol type: file
    file length: 5 GiB (5368709120 bytes)
    disk size: 4 KiB
```
Mục đích chuyển đổi:
- Tăng hiệu năng I/O
- Phù hợp khi cần tốc độ I/O cao

## Chuyển từ raw sang qcow2
Thực hiện chuyển đổi từ raw sang qcow2 và kiểm tra:
```
root@MANHLAB1:~# qemu-img convert -f raw -O qcow2 /var/lib/libvirt/images/converted_disk.raw /var/lib/libvirt/images/restored_disk.qcow2
```
Kiểm tra
```
root@MANHLAB1:~# qemu-img info /var/lib/libvirt/images/restored_disk.qcow2
image: /var/lib/libvirt/images/restored_disk.qcow2
file format: qcow2
virtual size: 5 GiB (5368709120 bytes)
disk size: 196 KiB
cluster_size: 65536
Format specific information:
    compat: 1.1
    compression type: zlib
    lazy refcounts: false
    refcount bits: 16
    corrupt: false
    extended l2: false
Child node '/file':
    filename: /var/lib/libvirt/images/restored_disk.qcow2
    protocol type: file
    file length: 192 KiB (197120 bytes)
    disk size: 196 KiB
```
## Kiểm tra
Check dung lượng các file khi chuyển đổi
```
root@MANHLAB1:~# ls -lh /var/lib/libvirt/images/*_disk.*
-rw-r--r-- 1 root root 5.0G Oct 29 14:39 /var/lib/libvirt/images/converted_disk.raw
-rw-r--r-- 1 root root 193K Oct 29 14:42 /var/lib/libvirt/images/restored_disk.qcow2
-rw-r--r-- 1 root root 193K Oct 29 14:36 /var/lib/libvirt/images/source_disk.qcow2
```
## Dọn dẹp
Sử dụng câu lệnh sau:
```
rm -f /var/lib/libvirt/images/*_disk.*
```
# Một số tiện ích
Hiển thị thông tin file disk:
```
qemu-img info disk.qcow2
```
Convert và tối ưu(nén Qcow2):
```
qemu-img convert -c -f raw -O qcow2 disk.raw disk.qcow2
```
Convert với tiến trình hiển thị:
```
qemu-img convert -p -f qcow2 -O raw disk.qcow2 disk.raw
```
# Một số lưu ý
Máy ảo phải tắt (shutdown) trước khi convert để tránh lỗi dữ liệu.

Cần đảm bảo đủ dung lượng ổ đĩa khi chuyển sang RAW (vì RAW = full size).

QCOW2 có snapshot → khi convert sang RAW sẽ mất snapshot.
