# LAB Netwrok KVM
Cài đặt và triển khai mạng cho máy ảo trong KVM

Mặc định các máy ảo trong KVM khi được khởi tạo sẽ mặc định được gán cơ chế NAT

## Cấu hình mạng thủ công
Trước tiên chúng ta kiểm tra các mạng mặc định

```
root@MANHLAB1:~# virsh net-list --all
 Name      State    Autostart   Persistent
--------------------------------------------
 default   active   yes         yes

root@MANHLAB1:~#
```
Xác nhận mạng mặc định được tạo(cơ chế NAT)

Bật mạng(nếu chưa)
```
root@MANHLAB1:~# virsh net-start default
error: Failed to start network default
error: Requested operation is not valid: network is already active

```
### Chế độ NAT (Network Address Translation)
Bước 1: Gắn card mạng NAT vào VM trên HostBash# Đảm bảo mạng default của KVM đang chạy
```
virsh net-start default

# Gắn vNIC của vm1 vào mạng NAT default
virsh destroy vm1
virt-xml vm1 --edit --network network=default
virsh start vm1
```
Bước 2: Bật mạng trong Alpine (vm1): Kết nối `virsh console vm1`, đăng nhập root và gõ: 

```
link set eth0 up
udhcpc -i eth0
```
Bước 3: Kiểm chứng hoạt động
- Kiểm tra IP: Gõ `ip a show eth0` $\rightarrow$ Nhận IP dải 192.168.122.x.
- Ping ra Internet: Gõ `ping -c 2 8.8.8.8` $\rightarrow$ Thành công (Host đóng vai trò Router SNAT gói tin ra ngoài).
- Ping từ PC ngoài LAN vật lý tới VM: `Thử ping 192.168.122.x` từ một máy khác ngoài mạng LAN $\rightarrow$ Thất bại (Mạng ngoài không thấy IP nội bộ của VM).
### Chế độ Isolated (Host-Only)
Bước 1: Tạo mạng Isolated bằng XML trên Host

Tạo file `isolated-net.xml`:
```xml
XML<network>
  <name>isolated-net</name>
  <bridge name='virbr1' stp='on' delay='0'/>
  <ip address='192.168.100.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.100.10' end='192.168.100.254'/>
    </dhcp>
  </ip>
</network>
```
Kích hoạt mạng và chuyển vm1 sang mạng Isolated:
```Bash
virsh net-define isolated-net.xml
virsh net-start isolated-net
virsh destroy vm1
virt-xml vm1 --edit --network network=isolated-net
virsh start vm1
```
Bước 2: Bật mạng trong Alpine (vm1)
```
link set eth0 up
udhcpc -i eth0
```
Bước 3: Kiểm chứng hoạt động
- Kiểm tra IP: Gõ `ip a show eth0` $\rightarrow$ Nhận IP dải 192.168.100.x.
- Ping tới máy Host: Gõ `ping -c 2 192.168.100.1` $\rightarrow$ Thành công (Giao tiếp được với Host).
- Ping ra Internet: Gõ `ping -c 2 8.8.8.8` $\rightarrow$ Thất bại (Do không có cơ chế Forwarding/NAT ra card thật của Host).
### Chế độ Bridged Networking (Linux Bridge)
Bước 1: Tạo Bridge br0 trên Ubuntu Host (bằng Netplan)

Chỉnh sửa file cấu hình Netplan trên Host (ví dụ `/etc/netplan/01-netcfg.yaml`):

```YAML:
  version: 2
  renderer: networkd
  ethernets:
    ens33:
      dhcp4: no
  bridges:
    br0:
      interfaces: [ens33]
      dhcp4: yes
```      
Áp dụng cấu hình và chuyển card của vm1 sang Bridge br0:
```Bash
sudo netplan apply

virsh destroy vm1
virt-xml vm1 --edit --network bridge=br0
virsh start vm1
```
Bước 2: Bật mạng trong Alpine (vm1)
```Baship 
link set eth0 up
udhcpc -i eth0
```
Bước 3: Kiểm chứng hoạt động
- Kiểm tra IP: Gõ ip a show eth0 $\rightarrow$ Nhận IP trực tiếp từ Router Wi-Fi/LAN thật (ví dụ 172.16.66.x hoặc 192.168.1.x).
- Ping ra Internet/Gateway: `Gõ ping -c 2 8.8.8.8` $\rightarrow$ Thành công.
- Ping hai chiều từ Máy khác ngoài LAN: Từ một PC vật lý khác trong LAN, ping trực tiếp tới IP của vm1 $\rightarrow$ Thành công (Giao tiếp Layer 2 trực tiếp).
