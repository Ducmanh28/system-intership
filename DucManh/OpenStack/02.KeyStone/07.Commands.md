# TỔNG HỢP CÂU LỆNH QUẢN TRỊ OPENSTACK KEYSTONE

Tài liệu này hệ thống hóa đầy đủ cú pháp chuẩn của bộ công cụ dòng lệnh **`openstack` CLI** (quản trị Identity v3 thông qua REST API) và **`keystone-manage`** (quản trị cấp hệ thống trực tiếp trên Controller Node).

> **Mẹo tra cứu nhanh trực tiếp trên Terminal:**
> * Xem toàn bộ nhóm lệnh của OpenStack Client: `openstack --help`
> * Xem danh sách lệnh thuộc nhóm Identity: `openstack identity --help`
> * Xem chi tiết tham số của một lệnh bất kỳ: `openstack <lệnh> --help` (ví dụ: `openstack user create --help`)
a
## 1. Quản lý Thực thể Định danh Cốt lõi (Core Identity)

### 1.1. Domain
```bash
# Tạo Domain mới
openstack domain create [--description <desc>] [--enable|--disable] <name>

# Liệt kê, xem chi tiết, cập nhật và xóa Domain
openstack domain list [--name <name>]
openstack domain show <domain>
openstack domain set [--name <new-name>] [--description <desc>] [--enable|--disable] <domain>
openstack domain delete <domain>
```

### 1.2. Project (Tenant)
```bash
# Tạo Project mới thuộc một Domain
openstack project create [--domain <domain>] [--description <desc>] [--enable|--disable] <name>

# Liệt kê, xem chi tiết, cập nhật và xóa Project
openstack project list [--domain <domain>] [--long]
openstack project show <project>
openstack project set [--name <new-name>] [--description <desc>] [--enable|--disable] <project>
openstack project delete <project>
```

### 1.3. User
```bash
# Tạo User mới (khuyến nghị chỉ định rõ --domain)
openstack user create [--domain <domain>] [--project <project>] [--password <pass>] [--email <email>] [--enable|--disable] <name>

# Liệt kê, xem chi tiết, cập nhật mật khẩu/trạng thái và xóa User
openstack user list [--domain <domain>] [--name <name>]
openstack user show <user>
openstack user set [--name <new-name>] [--email <email>] [--password <pass>] [--enable|--disable] <user>
openstack user delete <user>
```

### 1.4. Group
```bash
# Tạo, liệt kê, xem chi tiết, cập nhật và xóa Group
openstack group create [--domain <domain>] [--description <desc>] <name>
openstack group list [--domain <domain>]
openstack group show <group>
openstack group set [--name <new-name>] [--description <desc>] <group>
openstack group delete <group>

# Quản lý thành viên (User) bên trong Group
openstack group add user <group> <user>
openstack group remove user <group> <user>
openstack group contains user <group> <user>
```

### 1.5. Role & Role Assignment
```bash
# Tạo, liệt kê, xem chi tiết và xóa Role
openstack role create <name>
openstack role list
openstack role show <role>
openstack role delete <role>

# Gán Role cho User hoặc Group trên phạm vi Project / Domain / System
openstack role add --user <user> --project <project> <role>
openstack role add --user <user> --domain <domain> <role>
openstack role add --user <user> --system all <role>
openstack role add --group <group> --project <project> <role>

# Thu hồi Role
openstack role remove --user <user> --project <project> <role>

# Kiểm tra bảng phân quyền (thêm --names để hiển thị tên thay vì UUID)
openstack role assignment list [--user <user>] [--project <project>] [--names]
```

### 1.6. Implied Role (Vai trò Kế thừa Ngầm định)
```bash
# Thiết lập quy tắc: User có <prior-role> sẽ tự động hưởng quyền của <implied-role>
openstack implied role create <prior-role> --implied-role <implied-role>

# Liệt kê và xóa quan hệ kế thừa Role
openstack implied role list
openstack implied role delete <prior-role> --implied-role <implied-role>
```

## 2. Service Catalog, Region & Endpoint

```bash
# Quản lý Region
openstack region list
openstack region create [--description <desc>] <region-id>

# Quản lý Service (ví dụ: --type identity cho Keystone, --type compute cho Nova)
openstack service create [--description <desc>] [--enable|--disable] [--type <type>] <name>
openstack service list
openstack service show <service>
openstack service delete <service>

# Tạo 3 loại Endpoint (public, internal, admin) cho một Service
openstack endpoint create [--region <region>] <service> public <url>
openstack endpoint create [--region <region>] <service> internal <url>
openstack endpoint create [--region <region>] <service> admin <url>

# Liệt kê, xem chi tiết, chỉnh sửa và xóa Endpoint
openstack endpoint list [--region <region>] [--service <service>]
openstack endpoint show <endpoint>
openstack endpoint set [--url <new-url>] [--enable|--disable] <endpoint>
openstack endpoint delete <endpoint>

# Xem toàn bộ Service Catalog mà phiên đăng nhập hiện tại nhìn thấy
openstack catalog list
```

## 3. Token & Authentication

```bash
# Xin cấp Scoped/Unscoped Token mới dựa trên biến môi trường hoặc tham số hiện tại
openstack token issue

# Kiểm tra thông tin giải mã chi tiết của một Token
openstack token show <token>

# Thu hồi (vô hiệu hóa ngay lập tức) một Token đang lưu hành
openstack token revoke <token>
```
## 4. Application Credential (Xác thực cho Script & Automation)

Cho phép ứng dụng ngoài hoặc script tự động hóa xác thực với một Project và tập Role giới hạn mà không cần lưu mật khẩu chính của người dùng.

```bash
# Tạo Application Credential (Secret chỉ hiển thị duy nhất một lần lúc tạo)
openstack application credential create [--description <desc>] [--expiration <YYYY-MM-DDTHH:MM:SS>] [--role <role>] [--unrestricted] <name>

# Liệt kê, xem chi tiết và xóa Application Credential
openstack application credential list
openstack application credential show <credential-id-or-name>
openstack application credential delete <credential-id-or-name>
```

## 5. Federation (OIDC, SAML 2.0 & Keystone-to-Keystone)

```bash
# Quản lý Identity Provider (IdP) bên ngoài
openstack identity provider create [--description <desc>] [--remote-id <remote-id>] <name>
openstack identity provider list
openstack identity provider show <idp>
openstack identity provider set [--description <desc>] [--enable|--disable] <idp>
openstack identity provider delete <idp>

# Quản lý bộ quy tắc ánh xạ thuộc tính (Attribute Mapping) từ IdP sang Keystone
openstack mapping create <mapping-name> --rules <rules.json>
openstack mapping list
openstack mapping show <mapping>
openstack mapping delete <mapping>

# Liên kết giao thức xác thực (oidc, saml2...) giữa IdP và Mapping
openstack federation protocol create --identity-provider <idp> --mapping <mapping> <protocol>
openstack federation protocol list --identity-provider <idp>
openstack federation protocol show --identity-provider <idp> <protocol>
openstack federation protocol delete --identity-provider <idp> <protocol>
```

## 6. Unified Limits & Quota (Giới hạn Tài nguyên Tập trung)

Một số dịch vụ OpenStack hiện đại (như Nova, Cinder, Glance) sử dụng cơ chế Unified Limits lưu trên Keystone để quản lý hạn ngạch tập trung theo từng Project.

```bash
# Xem và tạo giới hạn mặc định toàn cục (Registered Limits)
openstack registered limit list
openstack registered limit create --service <service> --default-limit <value> [--region <region>] <resource-name>

# Xem và ghi đè giới hạn riêng cho từng Project (Project Limits)
openstack limit list
openstack limit create --project <project> --service <service> --resource-limit <value> [--region <region>] <resource-name>
```

## 7. Các lệnh Quản trị Hệ thống (`keystone-manage`)

Nhóm lệnh này chạy trực tiếp trên máy chủ cài đặt Keystone (thường dưới quyền `root` hoặc `su -s /bin/sh -c "..." keystone`).

### 7.1. Cơ sở dữ liệu & Khởi tạo ban đầu
```bash
# Kiểm tra phiên bản schema database hiện tại và đồng bộ bảng dữ liệu mới nhất
keystone-manage db_version
su -s /bin/sh -c "keystone-manage db_sync" keystone

# Khởi tạo thực thể gốc lần đầu (Admin user, Project admin, Default roles, Keystone endpoints)
keystone-manage bootstrap \
  --bootstrap-password <ADMIN_PASS> \
  --bootstrap-admin-url http://controller:5000/v3/ \
  --bootstrap-internal-url http://controller:5000/v3/ \
  --bootstrap-public-url http://controller:5000/v3/ \
  --bootstrap-region-id RegionOne
```

### 7.2. Quản lý Khóa Mã hóa (Fernet & Credential)
```bash
# Khởi tạo kho khóa Fernet Token lần đầu và xoay vòng định kỳ
keystone-manage fernet_setup --keystone-user keystone --keystone-group keystone
keystone-manage fernet_rotate --keystone-user keystone --keystone-group keystone

# Khởi tạo, xoay vòng và migrate khóa mã hóa Credential trong database
keystone-manage credential_setup --keystone-user keystone --keystone-group keystone
keystone-manage credential_rotate --keystone-user keystone --keystone-group keystone
keystone-manage credential_migrate --keystone-user keystone --keystone-group keystone
```

### 7.3. Quản lý Cấu hình Domain, LDAP & Kiểm tra Sức khỏe
```bash
# Nạp cấu hình riêng của từng Domain từ thư mục file vào SQL database
keystone-manage domain_config_upload --all
keystone-manage domain_config_upload --domain-name <domain>

# Đồng bộ trước hoặc xóa bảng ánh xạ ID khi tích hợp LDAP/AD
keystone-manage mapping_populate --domain <domain>
keystone-manage mapping_purge --domain-name <domain>

# Kiểm thử quy tắc ánh xạ Federation trên CLI trước khi đưa vào vận hành
keystone-manage mapping_engine --rules <rules.json> --input <assertion.txt>

# Tự động chẩn đoán các lỗi cấu hình, phân quyền thư mục khóa và database phổ biến
keystone-manage doctor

# [DEPRECATED] Xóa token hết hạn trong DB — không còn dùng vì Fernet/JWS là stateless
# keystone-manage token_flush
```
