## 1. Khởi tạo môi trường & kiểm tra sức khỏe dịch vụ

Luôn nạp tệp biến môi trường Keystone (`~/admin-openrc`) trước khi chạy lệnh CLI hoặc lấy token gọi REST API:

```bash
source ~/admin-openrc

# Kiểm tra tính sẵn sàng của Placement (DB, cấu hình, chính sách nâng cấp)
placement-status upgrade check

# Kiểm tra endpoint Placement trên Keystone (mặc định cổng 8778)
openstack endpoint list --service placement

# Kiểm tra Apache2 đang lắng nghe cổng 8778
ss -tlnp | grep 8778
```

Biến môi trường chuẩn dùng xuyên suốt cho các lệnh REST API bên dưới:

```bash
export TOKEN=$(openstack token issue -f value -c id)
export PLACEMENT_URL=$(openstack endpoint list --service placement --interface public -f value -c URL)
export API_VER="OpenStack-API-Version: placement 1.39"
```

## 2. Quản lý Resource Providers (RP) & Cây phân cấp Cha – Con

### Bằng `openstack` CLI

```bash
# Liệt kê toàn bộ Resource Providers
openstack resource provider list

# Tạo Resource Provider mới
openstack resource provider create --name LAB_RP_01

# Tạo Child Resource Provider (gắn vào parent UUID)
openstack resource provider create --name LAB_CHILD_01 --parent-provider "$PARENT_UUID"

# Xem chi tiết một Resource Provider (kèm generation, parent, root)
openstack resource provider show "$RP_UUID"

# Xóa Resource Provider (chỉ xóa được khi không còn allocation và không còn child RP)
openstack resource provider delete "$RP_UUID"
```

### Bằng REST API (`curl`)

```bash
# Liệt kê RP (hỗ trợ lọc theo name, uuid, member_of, resources, required...)
curl -s -H "X-Auth-Token: $TOKEN" -H "$API_VER" \
  "$PLACEMENT_URL/resource_providers" | python3 -m json.tool

# Tạo RP cha và RP con
ROOT_UUID=$(curl -s -X POST "$PLACEMENT_URL/resource_providers" \
  -H "X-Auth-Token: $TOKEN" -H "Content-Type: application/json" -H "$API_VER" \
  -d '{"name": "LAB_API_ROOT"}' | python3 -c "import sys, json; print(json.load(sys.stdin)['uuid'])")

curl -s -X POST "$PLACEMENT_URL/resource_providers" \
  -H "X-Auth-Token: $TOKEN" -H "Content-Type: application/json" -H "$API_VER" \
  -d "{\"name\": \"LAB_API_CHILD\", \"parent_provider_uuid\": \"$ROOT_UUID\"}" | python3 -m json.tool
```

## 3. Quản lý Inventory & Resource Classes

### Bằng `openstack` CLI

```bash
# Xem danh sách inventory trên một RP (hiển thị total, reserved, min, max, step, allocation_ratio, used)
openstack resource provider inventory list "$RP_UUID"

# Khai báo/cập nhật inventory cho VCPU trên RP
openstack resource provider inventory set "$RP_UUID" \
  --resource VCPU=total=4,reserved=1,min_unit=1,max_unit=4,step_size=1,allocation_ratio=2.0

# Xóa một resource class khỏi inventory của RP
openstack resource provider inventory delete "$RP_UUID" --resource VCPU

# Xem danh sách resource class (chuẩn và custom)
openstack resource class list
```

### Bằng REST API (`curl`)

```bash
# Đọc inventory hiện tại (lưu ý lấy resource_provider_generation mới nhất)
curl -s -H "X-Auth-Token: $TOKEN" -H "$API_VER" \
  "$PLACEMENT_URL/resource_providers/$RP_UUID/inventories" | python3 -m json.tool

# Ghi đè toàn bộ inventory của RP bằng PUT (cần đúng resource_provider_generation)
GEN=$(curl -s -H "X-Auth-Token: $TOKEN" -H "$API_VER" \
  "$PLACEMENT_URL/resource_providers/$RP_UUID" | python3 -c "import sys, json; print(json.load(sys.stdin)['generation'])")

curl -s -X PUT "$PLACEMENT_URL/resource_providers/$RP_UUID/inventories" \
  -H "X-Auth-Token: $TOKEN" -H "Content-Type: application/json" -H "$API_VER" \
  -d "{
    \"resource_provider_generation\": $GEN,
    \"inventories\": {
      \"VCPU\": {\"total\": 4, \"reserved\": 1, \"min_unit\": 1, \"max_unit\": 4, \"step_size\": 1, \"allocation_ratio\": 2.0},
      \"MEMORY_MB\": {\"total\": 8192, \"reserved\": 1024, \"min_unit\": 256, \"max_unit\": 8192, \"step_size\": 256, \"allocation_ratio\": 1.0}
    }
  }" | python3 -m json.tool
```

## 4. Quản lý Traits & Aggregates

### Bằng `openstack` CLI

```bash
# Liệt kê trait (lọc custom trait bằng grep)
openstack trait list | grep CUSTOM_

# Tạo custom trait (bắt buộc viết hoa và bắt đầu bằng CUSTOM_)
openstack trait create CUSTOM_LAB_NVME

# Gán trait cho Resource Provider
openstack resource provider trait set "$RP_UUID" --trait CUSTOM_LAB_NVME

# Liệt kê trait trên một RP
openstack resource provider trait list "$RP_UUID"

# Xóa custom trait khỏi hệ thống
openstack trait delete CUSTOM_LAB_NVME
```

### Bằng REST API (`curl`)

```bash
# Tạo custom trait qua PUT /traits/{name}
curl -i -s -X PUT "$PLACEMENT_URL/traits/CUSTOM_LAB_NVME" \
  -H "X-Auth-Token: $TOKEN" -H "$API_VER" | head -n 10

# Xem các aggregate mà RP đang tham gia
curl -s -H "X-Auth-Token: $TOKEN" -H "$API_VER" \
  "$PLACEMENT_URL/resource_providers/$RP_UUID/aggregates" | python3 -m json.tool
```

## 5. Truy vấn `Allocation Candidates` & Quản lý `Allocations`

### Bằng `openstack` CLI

```bash
# Tìm ứng viên thỏa mãn VCPU:2, MEMORY_MB:2048
openstack allocation candidate list --resource VCPU=2 --resource MEMORY_MB=2048

# Liệt kê allocation đang nằm trên một Resource Provider
openstack resource provider allocation list "$RP_UUID"
```

### Bằng REST API (`curl`)

```bash
# 1. Truy vấn allocation candidates kèm required/forbidden trait
curl -s -H "X-Auth-Token: $TOKEN" -H "$API_VER" \
  "$PLACEMENT_URL/allocation_candidates?resources=VCPU:2,MEMORY_MB:2048&required=CUSTOM_LAB_NVME" | python3 -m json.tool

# 2. Tạo/cập nhật allocation cho một consumer_uuid
CONSUMER_UUID="aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee"
PROJECT_ID=$(openstack project show admin -f value -c id)
USER_ID=$(openstack user show admin -f value -c id)

curl -i -s -X PUT "$PLACEMENT_URL/allocations/$CONSUMER_UUID" \
  -H "X-Auth-Token: $TOKEN" -H "Content-Type: application/json" -H "$API_VER" \
  -d "{
    \"allocations\": {
      \"$RP_UUID\": {\"resources\": {\"VCPU\": 2, \"MEMORY_MB\": 2048}}
    },
    \"project_id\": \"$PROJECT_ID\",
    \"user_id\": \"$USER_ID\"
  }" | head -n 10

# 3. Xem allocation hiện tại của consumer
curl -s -H "X-Auth-Token: $TOKEN" -H "$API_VER" \
  "$PLACEMENT_URL/allocations/$CONSUMER_UUID" | python3 -m json.tool

# 4. Xóa allocation của consumer (giải phóng tài nguyên)
curl -i -s -X DELETE "$PLACEMENT_URL/allocations/$CONSUMER_UUID" \
  -H "X-Auth-Token: $TOKEN" -H "$API_VER" | head -n 10
```

## 6. Bảng đối chiếu nhanh CLI vs REST API

| Mục đích | `openstack` CLI | REST API (`$PLACEMENT_URL`) |
| :--- | :--- | :--- |
| Danh sách RP | `openstack resource provider list` | `GET /resource_providers` |
| Inventory của RP | `openstack resource provider inventory list <rp>` | `GET /resource_providers/{rp_uuid}/inventories` |
| Cập nhật Inventory | `openstack resource provider inventory set ...` | `PUT /resource_providers/{rp_uuid}/inventories` |
| Danh sách Trait | `openstack trait list` | `GET /traits` |
| Tìm ứng viên cấp phát | `openstack allocation candidate list ...` | `GET /allocation_candidates?...` |
| Allocation theo RP | `openstack resource provider allocation list <rp>` | `GET /resource_providers/{rp_uuid}/allocations` |
| Xóa Allocation consumer | *(thường làm qua Nova hoặc REST API)* | `DELETE /allocations/{consumer_uuid}` |
