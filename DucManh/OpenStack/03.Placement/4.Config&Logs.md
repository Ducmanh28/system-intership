# File Log và Config của Placement
Khác với các dịch vụ có nhiều daemon riêng biệt, Placement vận hành như 1 ứng dụng WSGI chạy bên trong Apache2 và lắng nghe ở cổng `8778`. 

## Cấu trúc file cấu hình 
Location: `/etc/placement/placement.conf`

- `[DEFAULT]`: Các tham số chung của dịch vụ, bao gồm:

  - `debug = False` (chỉ bật True tạm thời khi cần soi chi tiết request/response hoặc luồng xử lý lúc debug; bật lâu dài sẽ làm log phình nhanh và tốn I/O).
  - `log_dir = /var/log/placement` (thư mục ghi log của Placement).

- `[placement_database]`: Kết nối tới cơ sở dữ liệu placement trên MariaDB:

```Ini, TOML
[placement_database]
connection = mysql+pymysql://placement:28072003@172.16.66.60/placement
```
- `[api]`: Quy định cơ chế xác thực khi tiếp nhận request HTTP:

```Ini, TOML
[api]
auth_strategy = keystone
```
- `[keystone_authtoken]`: Thông tin để middleware xác thực token của người dùng/dịch vụ qua Keystone và cache token qua Memcached:

```Ini, TOML
[keystone_authtoken]
auth_url = http://172.16.66.60:5000/v3
memcached_servers = 172.16.66.60:11211
auth_type = password
project_domain_name = Default
user_domain_name = Default
project_name = service
username = placement
password = 28072003
```
Quyền sở hữu & bảo mật file cấu hình

Vì `/etc/placement/placement.conf` chứa thông tin đăng nhập database và tài khoản dịch vụ Keystone:
- Owner / Group: `root:placement`
- Permission: `0640`

Lệnh kiểm tra và siết quyền chuẩn:

```Bash
ls -la /etc/placement/
chown root:placement /etc/placement/placement.conf
chmod 0640 /etc/placement/placement.conf
```
Cấu hình Apache2 / WSGI liên quan đến Placement

Khi cài `placement-api`, gói cài đặt sẽ tạo cấu hình Apache2 (trong `/etc/apache2/sites-available/` hoặc `/etc/apache2/conf-available/` và symlink sang `*-enabled/`) để ánh xạ cổng `8778` vào WSGI application của Placement.

Lệnh kiểm tra nhanh cấu hình Apache2 và cổng lắng nghe:
```Bash
apache2ctl -S
ss -tlnp | grep 8778
```
## Hệ thống Log của Placement
Có 3 nguồn Log chính tùy theo tầng xảy ra sự cố:

|Nguồn|Đường dẫn/Lệnh|Nội dung ghi nhận|Thời điểm dùng|
|-|-|-|-|-|
|Log ứng dụng|/var/log/placement|Lỗi xử lý nghiệp vụ, SQL/DB, Keystone, traceback|Khi API trả 401, 409, 500 hoặc lỗi truy vấn DB / token|
|Log Web Server Apache2|/var/log/apache2/error.log(access.log)|Lỗi khởi tạo WSGI process, lỗi quyền truy cập file/socket, lỗi VirtualHost hoặc HTTP status/access log.|Khi không kết nối được tới cổng 8778, lỗi 500 hoặc lỗi tiến trình WSGI|
|Systemd Journal|journalctl -u apache2 -n 100 --no-pager|Log vòng đời dịch vụ apache2 và thông điệp từ systemd|Khi apache2 khởi động bị lỗi hoặc bị hệ thống can thiệp|
